## Organisation du dépôt

```
configs/partie-1/   fichiers de configuration (SW1, R1)
images/partie-1/    captures d'écran de la partie 1
PARTIE-1-...md      documentation de la partie 1
```

Chaque nouvelle partie ajoute son fichier `PARTIE-N-...md` et ses dossiers `configs/partie-N/` et `images/partie-N/`.

> Les images IOS Cisco (`.bin`) ne sont pas publiées dans ce dépôt (licence).
